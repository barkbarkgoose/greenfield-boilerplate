Quick-Learn Architecture Guide

Dynamic Port Discovery

How the greenfield-boilerplate handles port collisions and environment wiring.

1. The 10-Second Anchor

A bootstrapper that probes TCP ports before starting services to avoid "Address already in use" errors.

Category & Core Job: Local orchestrator that ensures a crash-free boot by dynamically adjusting ports and injecting them into environment variables.

2. The Conceptual Ladder

1

Hardcoded Ports

Most apps assume port 8000 or 5173. If another project is running, the app crashes immediately.

2

The Probe

Instead of blindly starting, the script tries to bind to the port. If it fails, the port is occupied.

3

Incremental Hunting

If occupied, the script increments the port (e.g., 8800 → 8801) until it finds a hole.

4

Dynamic Wiring

The discovered ports are injected into the child processes via environment variables (VITE_API_URL) so the frontend knows where the backend landed.

5

Zero-Config Boot

The developer just runs one script, and the system self-organizes regardless of what else is running on the machine.

4. The Cast of Characters

1. Probe is_port_available()

The Socket Tester

Tries to bind to a TCP port briefly to see if it's free.

  • Owns: Boolean status of a port.
  • Interface: Socket bind attempt.
2. Orchestrator main()

The Conductor

Coordinates the probe and launches the servers with the right flags.

  • Owns: Child process lifecycle, signal handling.
  • Interface: Subprocess.Popen.

5. The Lifecycle Walkthrough

Scenario: User runs ./dev.sh while another app occupies port 8800.

sequenceDiagram participant User participant dev.py participant Socket participant Django participant Vite User->>dev.py: Run dev.sh dev.py->>Socket: Check port 8800 Socket-->>dev.py: Refused (Occupied) dev.py->>Socket: Check port 8801 Socket-->>dev.py: Success (Free) dev.py->>Django: start --port 8801 dev.py->>Vite: start --port 5177, VITE_API_URL=8801
  1. Probe: find_next_available_port searches starting at 8800.
  2. Discovery: Port 8801 is identified as free.
  3. Injection: VITE_BACKEND_TARGET is set to http://127.0.0.1:8801.
  4. Execution: Django is launched specifically on port 8801.
  5. Connection: Vite starts and its proxy uses the injected 8801 target.

7. Field Guide & Sharp Edges

⚠️ Sharp Edge: Localhost vs 127.0.0.1

On macOS, localhost might resolve to IPv6 (::1) while the server binds to IPv4 (127.0.0.1). The boilerplate handles this by explicitly using IPv4 for binds.

💡 Tip: Environment Variables over Configs

Avoid putting पोर्टs in vite.config.ts. Use process.env.VITE_BACKEND_TARGET so the orchestrator can change them on the fly.
